# رادار البلاك فرايدي

موقع بيجمع عروض البلاك فرايدي 2026 من المتاجر المصرية (جوميا، أمازون مصر، نون، وغيرهم) في صفحة واحدة.

- `index.html`: الصفحة الرئيسية (الهيرو، مواعيد الحملات، الفلاتر، والعروض بصفحات).
- `product.html?id=...`: صفحة تفاصيل المنتج ومعاها عروض شبهه.
- `assets/style.css` و`assets/common.js`: الستايل والكود المشترك بين الصفحتين. مفيش build.
- `data/deals.json`: العروض ومواعيد حملات المتاجر. الصفحة بتقرا الملف ده كل 5 دقايق.
- `scripts/check.mjs`: بيتأكد إن `data/deals.json` سليم قبل الرفع (`node scripts/check.mjs`).

بتحدّث العروض مهمة مجدولة في Claude ("تحديث رادار البلاك فرايدي")، وبتشتغل 3 مرات في اليوم. كل مرة بتعدّل `data/deals.json` وتعمل commit وpush، وGitHub Pages بينشر التحديث لوحده.
